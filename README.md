# Khalil Housheya — Portfolio

## Run it (2 steps)

```bash
npm install
npm run dev
```

Open the link it prints — usually **http://localhost:5173**

That's it. Edit `src/App.tsx` for layout, `src/translations.js` for text (EN/AR/RU), 
`src/index.css` for styling, and replace files in `src/assets/` to swap images.

## Build for deployment

```bash
npm run build
```

Output goes to `dist/` — upload that folder to Vercel, Netlify, or GitHub Pages.
